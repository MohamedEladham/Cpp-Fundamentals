# Cpp-Fundamentals

A repository documenting my C++ learning journey, covering core programming concepts, hands-on exercises, and practical implementations.

## 🏗️ Repository Structure

The repository is organized into two main levels:

```text
cpp-fundamentals/
│
├── Level1/   → Core C++ Programming Fundamentals (35 modules)
└── Level2/   → C++ Advanced Topics & Features (18 modules)
```

## 🚀 Level 1 – Core C++ Programming Fundamentals

Focuses on essential programming concepts, syntax, and foundational problem-solving across **35 structured modules**:

* **Basics & I/O:** Output printing, variables, user inputs, and data type sizes.
* **Operators & Math:** Arithmetic operators and basic calculator implementation, increment/decrement, assignment operators, relational operators, logical operators, and math functions using `<cmath>`.
* **Data Modeling & Enums:** Structures (`structs`), enums for days of the world, color selection, and weekday menu systems.
* **Type Management & Strings:** Type casting, string conversion, and string operations.
* **Functions & Scope:** Basic functions, procedures, function practice sets, scope resolution operator, and pass-by-reference memory demonstrations.
* **Control Flow & Loops:** Conditional statements (`if`, `else if`, `switch-case`), nested conditional menus, `for` loop iteration patterns, array processing systems such as sum and average, and nested loops for pattern printing.
* **Input Validation & Control:** Input validation using `for` and `while` loops, `do-while` loops, and loop control statements (`break` and `continue`).
* **Modularization:** Creating and organizing my first custom library (`My_First_Library`).

## 🚀 Level 2 – C++ Advanced Topics

Covers advanced C++ features, data structures, memory management, and system-level operations across **18 specialized modules**:

* **Advanced Syntax & Operators:** Ternary operators, range-based `for` loops, and bitwise operators (`AND`, `OR`).
* **Advanced Functions:** Function declaration and definition separation, default parameters, function overloading, recursion for printing and power calculations, and static local variables.
* **Modern C++ Features & Formatting:** `auto` keyword basics and output formatting.
* **Advanced Data Structures:** Two-dimensional matrices (`Two_Dimensional_Arrays`) and dynamic vectors (`Vector`).
* **Memory Management:** References, pointers, and dynamic memory allocation using `new` and `delete`.
* **System & File Operations:** File handling systems (`Files`) and Date & Time library implementations (`Date_Time`).

## 📌 Repository Goal

This repository serves as a personal learning archive that demonstrates my progress in C++ programming, problem-solving, clean code practices, and software development fundamentals.
